# 🍎 Fruit Catcher PLUS – Java Game

## 📌 Project Overview

**Fruit Catcher PLUS** is a fun and interactive 2D arcade game developed using **Core Java and Java Swing**.

The player controls a basket to catch falling fruits, earn points, avoid bombs, and unlock increasingly challenging levels.

This project demonstrates fundamental Java programming concepts, Object-Oriented Programming (OOP), GUI development, keyboard event handling, and collision detection.

## 🎮 Game Features

- 🍎 Multiple falling fruits
- 🧺 Smooth basket movement using arrow keys
- 💣 Bomb obstacles with explosion animation
- ⭐ Five difficulty levels
- 🏆 Score and high-score tracking during gameplay
- ❤️ Five lives
- ⚡ Increasing speed and difficulty
- 🌟 Golden fruits with bonus points
- ⏸️ Pause and resume functionality
- 🔄 Game over and restart option
- 🌐 Browser-playable version using GitHub Pages

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| Java | Core game logic |
| Java Swing | Graphical user interface |
| Java AWT | Graphics and keyboard events |
| OOP | Classes, objects and methods |
| HTML, CSS, JavaScript | Optional browser version |

No advanced frameworks or external game engines are required for the Java game.

## ▶️ How to Run the Java Game

**Requirements:** Java Development Kit (JDK)

1. Download or clone the repository.
2. Open the folder containing the Java files in VS Code.
3. Open the terminal.
4. Compile the Java files:

```bash
javac Main.java GamePanel.java Basket.java Fruit.java
```

5. Run the game:

```bash
java Main
```

## 🎯 Game Controls

| Key | Action |
|---|---|
| Left Arrow | Move basket left |
| Right Arrow | Move basket right |
| Enter | Start game |
| P | Pause / Resume |
| R | Restart after game over |
